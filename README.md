# Cléverson Imóveis — Demonstração

Site imobiliário demonstrativo desenvolvido com React + Vite + TypeScript.

## Executar

```bash
npm install
npm run dev
```

Depois acesse o endereço informado pelo Vite, normalmente `http://localhost:5173`.

## Estrutura

- `src/data/imoveis.ts`: dados fictícios dos imóveis.
- `src/components/`: componentes reutilizáveis.
- `src/pages/`: páginas do site.
- `src/styles/global.css`: identidade visual e responsividade.

## Observação

Esta versão é somente frontend para demonstração. Não possui backend, banco de dados, autenticação ou painel administrativo.

Os dados dos imóveis são fictícios e as imagens são carregadas do Unsplash. Antes de uma publicação comercial, substitua os dados, contatos e imagens pelos conteúdos autorizados pelo cliente.
